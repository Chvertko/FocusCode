# FocusCode

FocusCode — Android app to reduce screen time by requiring the user to solve coding challenges to open distracting apps.

This repository will contain a Kotlin + Jetpack Compose Android application using an AccessibilityService to intercept launches of selected apps and show a challenge overlay.

This initial commit creates the repository and will be expanded on a feature branch `feature/focus-code` with a minimal MVP implementation.

See `feature/focus-code` branch for the implementation.
